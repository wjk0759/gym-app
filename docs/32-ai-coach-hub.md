# 32 · AI 教练统一入口（Coach Hub）

## 1. 产品原则

AI 教练是 FitAI 的主入口。用户不需要先想「这个功能在哪个 Tab」，而是直接对教练说：

- 「帮我排个碳循环」
- 「拍张照看看这个器械怎么练」
- 「我想减脂，重新排计划」
- 「看看我的体态，重点练哪」
- 「把明天训练改到周四」

教练负责理解、追问、给方案、执行、回执。独立页面保留，但只作为深链/兜底。

## 2. 能力矩阵

| 能力 | 教练意图 | Action / Tool | 后端 | 前端结果 |
|---|---|---|---|---|
| 饮食策略 | 均衡/碳循环/低碳/高蛋白/地中海/素食/16:8 | `create_diet_plan` | `POST /diet/plan/week` | 一周高低碳卡 + 每天餐单 |
| 单日餐单 | 今天吃什么/换一餐 | `create_diet_plan` | `POST /diet/plan` | 餐单卡 |
| 体型分析 | 拍照看体态/训练重点 | `analyze_body` | `POST /body/analyze` | 分析卡 + 应用/继续聊 |
| 器械识别 | 拍器械/这是什么器械 | `recognize_equipment` | `POST /equipment/scan` | 候选卡 + 加入个人库 |
| 训练计划 | 重新排计划/换分化 | `create_training_plan` | `POST /plans/generate` | 计划预览 + 应用 |
| 计划调整 | 时间不够/疼/平台 | `adjust_training_plan` | `POST /plans/{id}/adjust` | 调整卡 + 确认 |
| 改期/跳过/开始 | 明天没空/开始训练 | 已有 actions | schedule/workout | 操作卡 |
| 目标/身体数据 | 改目标/记体重 | 已有 actions | goal/body | 操作卡 |

## 3. 统一交互

```text
用户一句话
  → 教练判断意图（能力路由）
  → 信息不足：只问一个关键问题
  → 信息足够：生成方案卡（预览，不直接写库）
  → 用户确认
  → 执行 action
  → 回执：做了什么、写到哪里、可撤销
  → 结果继续留在对话里
```

### 方案卡要求

- 说明「我准备做什么」和「为什么」。
- 关键数字/日期/策略必须可见。
- 高风险动作（改计划、写饮食、加器械）必须二次确认。
- 用户可以「再改一点」，教练重新生成，不重复问已知信息。

## 4. 能力路由

- 纯知识/情绪/离题：`/coach/chat`
- 需要查数据/写数据/执行：`/agent/chat` + action
- 安全红线：任何路径都先过 `detect_safety`
- 需要拍照：教练发「拍照」能力卡，前端弹相机，结果回传教练
- 需要页面：`open_screen` 作为兜底，不是主路径

## 5. 落地顺序

### P0 饮食（当前）
- 策略注册表：均衡、碳循环、低碳、高蛋白（v1）；地中海、素食、16:8 预留
- 一周计划：复用 `meal_plans`，每天一行，`plan` JSON 存 `strategy` + `day_type`
- 教练 action：`create_diet_plan`（预览 → 确认 → 写库）
- iOS：教练对话里的「一周饮食计划卡」+ 饮食页策略选择

### P1 器械识别
- 教练 `recognize_equipment`：拍照 → 候选 → 确认加入个人动作库
- 库外器械：自定义动作 + `source=recognition`，后台可查

### P2 体型分析
- 教练 `analyze_body`：拍照 → 分析卡 → 应用到计划 / 继续聊
- 分析结果作为对话上下文

### P3 训练计划
- 教练 `create_training_plan` / `adjust_training_plan`
- 计划预览卡 + 确认应用；失败回退规则模板

## 6. 安全与边界

- 医疗红线、孕期、术后、进食障碍、自伤：先转介，不进入能力执行。
- 饮食策略：疾病人群只给均衡；低碳/断食/生酮额外提示，不默认推荐。
- 训练计划：只引用动作库 slug；伤病过滤；不做医疗诊断。
- 所有写操作必须可追溯、可撤销，并在对话里说明。

## 7. 技术约定

- 新能力只加 action，不新开独立功能模块。
- action payload 用明确 schema，前端可渲染方案卡。
- 执行结果写回数据库后，教练必须给一句「已写入哪里」。
- 现有模块优先：饮食策略属于饮食计划；器械识别复用动作库/个人库；体型分析复用 `body_analysis`。
