## 4. 个人信息保护（PIPL）

| 事项 | 说明 | 状态 |
|---|---|---|
| 隐私政策 | 中文、逐项列明收集目的/方式/范围/保存期限/共享方 | ☐ |
| 敏感个人信息 | 健康、体围、体脂、**体型照片**属敏感信息，需**单独同意**（不能混在总协议里） | ☐ |
| 体型照片 | 明确用途、单独同意、不长期保存原图、不做体脂/医疗诊断、支持删除 | ☐ |
| 最小必要 | 不收集与功能无关的数据；三围、体脂设为选填 | ☐ |
| 个人信息保护影响评估（PIPIA） | 处理敏感信息前完成并留存 | ☐ |
| 账号注销 | App 内可完成，15 天冷静期，之后删除 | ☐ |
| 数据导出 | 提供 JSON/CSV 导出 | ☐ |
| 数据出境 | 若调用境外模型或海外服务器，需评估/单独同意/可能的出境评估；**建议境内闭环** | ☐ |
| 第三方 SDK 清单 | 逐项披露（推送、统计、崩溃、支付） | ☐ |
| 儿童/未成年人 | 14 岁以下需监护人同意；建议首版限制 18+ | ☐ |
| 数据安全 | 加密存储、访问审计、员工权限最小化 | ☐ |
| 等保 | 用户规模上来后评估等保 2.0 二级 | 后续 |

## 5. 医疗健康边界

| 风险 | 做法 |
|---|---|
| 被认定为医疗建议 | 全站声明“非医疗建议，不替代医生诊断”；不做疾病诊断、康复处方、用药建议 |
| 高风险人群 | 孕期、术后、心血管疾病、进食障碍用户不生成训练/饮食处方，引导就医 |
| 极端目标 | 减重 ≤0.5kg/周、增重 ≤0.25kg/周；BMI <18.5 禁止减脂目标 |
| 疼痛/不适 | 问答触发红旗症状即停止建议，提示就医 |
| 广告用语 | 不使用“治疗”“治愈”“康复”“最有效”等词 |
| 体型内容 | 避免身材羞辱、极端对比图；目标体型用围度/体脂而非“完美身材” |

## 6. Apple App Store 审核要点

| 条款 | 要求 | 本产品动作 |
|---|---|---|
| 5.1.1 | HealthKit 数据仅用于健康健身，不得用于广告/出售；需隐私政策与用途说明 | P1 接入前准备；当前未启用 |
| 5.1.2 | 数据收集需告知与同意；ATT（若追踪） | 隐私标签如实填写 |
| 1.4.1 | 不得提供医疗诊断/治疗建议 | 免责声明 + 安全兜底 |
| 3.1.1 | 数字内容/订阅必须用 IAP | AI 订阅走 StoreKit 2，不引导外部支付 |
| 3.1.3 | 实物商品/线下服务可外部支付 | 外卖跳转属实物，允许 |
| 2.5.1 | 禁止私有 API | 不使用逆向的美团 URL Scheme，只用官方 CPS 链接 |
| 4.2 | 需有完整核心功能，不能是简单聚合 | 建档→计划→记录→调整闭环 |
| 5.1.1(v) | 支持账号删除 | App 内提供注销 |
| 2.3.1 | 隐藏功能/虚假描述 | 商店截图与实际一致 |
| 1.2 | UGC 需审核/举报/屏蔽 | P0 无社区，AI 对话需内容审核 |

**权限文案（Info.plist）必须具体：**

- 相机：“用于拍摄健身器械，识别器械并展示使用方法。”
- 相册：“用于选择器械照片进行识别。”
- 通知：“用于在您设定的训练时间提醒您开始训练。”
- 健康（P1）：“用于读取体重与训练数据，写入完成的训练记录。”

## 8. 美团外卖

| 事项 | 说明 |
|---|---|
| 主体资质 | 美团联盟通常要求企业主体、媒体/推广位审核 |
