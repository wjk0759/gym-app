# 18 · 自选训练编排与训练中调整

## 流程

```text
今日页「开始训练」 ───────────────┐
                                    ├→ 安排训练（复用同一个编排组件）
器械页选择动作 → 制作训练计划 ─────┘   → 开始本次训练
                                      → 训练中可随时「调整」当前动作的目标
```

今日计划进入编排页时使用计划快照，训练中的顺序和负重调整不会写回长期计划。
器械页选择动作进入编排页时使用已选动作，开始后才清空已选动作。

### 训练前编排

- 动作可以上移 / 下移，保存当前训练的顺序。
- 每个动作可设置组数、每组次数、目标重量和组间休息。
- 默认值是 3 组、10-12 次、60 秒休息；重量来自动作基础值，没有则为 0（自重）。
- 开始按钮固定在底部安全区上方，长列表只滚动中间内容。
- 取消编排不会清空已选动作；开始训练后才清空已选动作。
- 自选训练只生成一次训练，不改长期计划。

### 训练中调整

- 当前动作的设置卡右上角提供「调整」。
- 可修改本次训练的目标组数、次数、重量、休息。
- 调整只写入 `workout.adjustments`，不修改长期计划模板。
- 调整进度会立即更新训练总组数。
- 如果减少到已完成组数以下，主按钮会切换为「下一个动作 / 查看训练总结」。
- 当前组实际完成的重量和次数仍通过重量、次数步进器记录；调整目标不会重写已完成的训练记录。

## 原生实现

- `CustomWorkoutBuilderView`
  - 今日计划和已选动作共用的编排页
  - 支持上下移动、删除、组数 / 次数 / 重量 / 休息编辑
  - 底部安全区固定开始按钮
- `HomeView`
  - 「开始训练」先进入 `CustomWorkoutBuilderView(mode: .plan)`
  - 编排完成后再呈现 `WorkoutSessionView`
- `EquipmentPickerView`
  - 「制作训练计划」进入同一个 `CustomWorkoutBuilderView`
  - 编排完成后再呈现 `WorkoutSessionView`
- `WorkoutSessionView`
  - `adjustedExercises` 保存本次训练的临时目标
  - 「调整」sheet 修改当前动作
  - 进度、目标组数和完成后的下一步都使用调整后的值

## Web 实现

- 新增 `workoutComposeScreen()`
- 新增 `workoutAdjustSheet()`
- `workoutDraft` 保存编排草稿
- `adjustedWorkoutExercises()` 将本次训练的临时目标叠加到计划动作上
- 训练页使用独立滚动壳，编排页同样使用固定头部 / 底部操作区

## 验收

- 点击「制作训练计划」不会直接进入训练。
- 今日页点击「开始训练」同样先进入编排页，并复用同一套动作编辑组件。
- 编排页能调整顺序、组数、次数、重量、休息，并开始训练。
- 训练页「调整」能修改当前动作目标，进度立即变化。
- 将目标组数降到已完成组数后，可以直接进入下一个动作。
- 长列表、320 宽和横屏下开始按钮不滑出屏幕。
- 长期计划训练日和自选训练都不会被训练中的临时调整改写。
