# 61 · Notes-like clean redesign（try 分支）

> 分支：`try`，从 `develop` `a9ebaff` 起。
> 未合并、未部署、未修改后端。目标是先做一轮可运行的整体收敛，后续再逐页细化。

## 方向

像苹果备忘录一样：

- 一个页面只做一件事。
- 一个区域只有一个主操作。
- 先改布局，不靠标语、说明文字和次要标签解释页面。
- 保留现有四色主题：lime 主色、ink 文字、paper 卡片、canvas 背景。
- 所有后端能力仍然可用，只更换入口和表达方式。

## 设计系统

- `AppType`：从海报式黑体改为系统半粗/常规字重，正文 16、标题 22、主标题 26。
- 卡片：去掉 `editorialCard` 的粗黑边和顶部色条，统一为 1px 边框的平卡。
- 指标：`EditorialMetric` 去掉独立卡片背景，只留数字和标签。
- `SectionTitle` / `EditorialHeader`：只显示标题，不再渲染副标题。
- 次要按钮：边框从重黑改为 `Theme.stroke`，降低视觉噪音。
- 删除 `TypewriterText`、`WeatherBadgeView` 等不再使用的展示组件。
- 全仓去掉 `TODAY /`、`SESSION /`、`PLAN /` 这类英文眉标，只保留中文信息。

## 页面变化

### 今日

- 删除问候语、昵称大标题、教练笔记、目标/周报折叠区。
- 删除天气药丸，只在有天气预警时显示一行提示。
- 周日期条下只保留：今日训练 / 三个快捷操作 / 今日饮食。
- 训练卡去掉 `TODAY`、周次、状态标签和三列指标；只留训练名、动作数/时长、前三个动作和主按钮。
- 快捷操作改为三个纯图标入口：记录身体、变化、拍照识别。
- 目标在「我的」，周复盘在「变化」，不再挤在首页。

### 记录

- 使用系统导航标题「训练手账」，删除自定义眉标、月份印章和「翻回去看…」文案。
- 日历去掉「月历」标题、图例和多余圆点，只保留月份切换、日期和单一状态点。
- 选中日卡去掉重复状态、说明性副标题和三列指标。
- 保留饮食摘要、训练动作、改期/跳过/编辑等全部能力。

### 教练

- 欢迎卡改为四条建议问题，直接可点，不再有「我是你的教练」和配额徽标。
- 删除本周状态卡和欢迎语；周复盘仍在「变化」。
- 导航标题改为「教练」，输入框占位改为「给教练发消息」。
- 保留所有动作卡、控制面、附件、撤销和额度耗尽卡。

### 发现

- 使用系统导航标题「发现」。
- 器械库从大型 hero 卡改为一行入口，保留件数/动作数。
- 训练、饮食、体型、动作库、拍照识别、动作点评改为分组列表行，去掉副标题和箭头装饰。
- 保留全部 sheet、Pro 门禁和既有路由。

### 我的

- 使用系统导航标题「我的」。
- 删除 `PROFILE /` 眉标和「训练、身体和目标，都在这里」文案。
- 保留账号、目标、身体数据、训练重点、体型分析、器械库。
- 删除 Pro 行「解锁全部功能」、目标免责声明、体型分析说明文字和累计训练摘要。

### 登录 / Onboarding

- 登录页删除「AI 健身教练」「训练 · 饮食 · 复盘」「同步计划…」和未注册提示。
- Onboarding 欢迎页从打字机标语改为 logo + 叫练 + 开始/恢复档案/退出。
- Step 标题只保留问题本身，不再渲染 eyebrow 和说明段。
