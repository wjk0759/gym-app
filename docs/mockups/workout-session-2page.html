结构说明

固定

进度头 + 动作头 + 页签
训练中永远知道第几个动作、第几组、目标是多少。

固定

第几组 / 上次 / 重量 / 次数
记录页上半屏不滚动，输入永远在首屏。

可滚动

最佳 / RPE / 换器械 / 撤销
次要信息才滚动，不再和主输入抢位置。

固定

休息条 + 完成按钮
两页都能看到休息时间，也都能直接完成本组。

这一版去掉或缩小的 UI

  • 视频从记录页移到演示页，记录页不再被 1:1 视频占掉半屏。
  • 大号动作卡缩成两行固定头，动作序号交给进度头。
  • 步进选择整行收进「步进 2.5 kg」菜单。
  • 自重说明整行改成次数行左侧的小标签（本示例为器械动作，所以显示重量）。
  • 上次 / 最佳两行合并，最佳移到可滚动区。
  • RPE 横向 Slider 改步进，避免和左右滑动抢手势。
  • 动作要点 / 训练提示移到演示页。
  • 大休息卡改成 34pt 休息条。
  • 「动作演示」角标删除，页签已经说明当前页面。
交互只用于看结构：点页签或左右拖动切换页面；+ / − 调重量、次数、RPE；点「步进」循环 1.25 / 2.5 / 5 kg。
