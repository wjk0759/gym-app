重量、次数、完成按钮全部固定在底栏，任何一页都能调、都能完成。上面的页面只负责“数据”和“演示”。代价是底栏比 A 高，视频页可视高度更小。

点击页签 / 左右拖动；演示页可上滑

结构说明

固定

进度头 + 动作头 + 页签
训练中永远知道第几个动作、第几组、目标是多少。

固定

底栏组记录器
第几组 / 重量 / 次数 / 完成按钮始终在拇指区。

可滚动

数据页
今天已完成组、上次 / 最佳、RPE、换器械、撤销。

固定

休息倒计时并入底栏
不再单独占一条；休息时底栏顶部出现 2px 进度线。

A vs B：真实取舍

方案 A

输入在记录页，底栏轻；视频页更完整。看视频时想改重量，要滑回记录页。

方案 B

底栏就是输入，任何页都能改、都能完成；底栏高约 40–50pt，SE 上视频页更挤。

这一版去掉或缩小的 UI

  • 重量 / 次数从页面内容移到底栏，数据页不再放大号输入。
  • 大号动作卡缩成两行固定头，动作序号交给进度头。
  • 步进选择收进底栏的「步进 2.5 kg」菜单。
  • 上次 / 最佳合并进一张历史卡，不再两行散落。
  • RPE 横向 Slider 改步进，避免和左右滑动抢手势。
  • 大休息卡取消，倒计时和进度线并入底栏。
  • 动作要点 / 训练提示只放在演示页。
  • 「动作演示」角标删除，页签已经说明当前页面。
交互只用于看结构：点页签或左右拖动切换；+ / − 调重量、次数、RPE；点「步进」循环 1.25 / 2.5 / 5 kg；点「跳过」收起休息。
