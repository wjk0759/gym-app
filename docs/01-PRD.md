# 01 · 产品需求文档（P0）

- 产品：FitAI（中文暂定「练途」）
- 版本：v0.1 / P0
- 市场：中国大陆
- 平台：iOS 17+（AlarmKit 需 iOS 26+）
- 更新：2026-10

---

## 1. 一句话定位

一个会记住你练过什么、并据此调整计划的 AI 健身教练，而不是一个只会给模板的训练 App。

## 2. 目标用户

| 用户 | 特征 | 核心诉求 |
|---|---|---|
| 健身新手 | 18–35 岁，去健身房但不知道怎么练 | 有人告诉我今天练什么、怎么做 |
| 减脂人群 | 有体重/围度目标，自律性一般 | 计划明确、到点提醒、能看到变化 |
| 回归用户 | 练过一段时间，停练后想恢复 | 不要从零开始，按历史水平恢复 |
| 器械小白 | 不敢用自由重量，看不懂器械 | 拍照就能知道器械怎么用 |

**不服务：** 需要医疗康复、术后恢复、孕期训练、专业运动员周期化训练的人群。

## 3. 核心价值与差异

1. **计划可编辑**：AI 生成的不是黑盒课表，用户能换动作、改组次，AI 记住这些偏好。
2. **训练记忆**：记录到每一组，按完成率、RPE、重量趋势做周期调整。
3. **到点真的会响**：用系统级提醒降低“今天练什么”的决策成本。
4. **器械即问即学**：拍照识别 → 动作卡片 → 教学视频，降低健身房门槛。

## 4. 核心闭环

```
首次建档 ──► 设定目标 ──► AI 生成 4 周计划 ──► 用户编辑确认
                                                    │
                                                    ▼
        训练记录 ◄── 执行训练 ◄── 到点提醒 ◄── 计划写入日历
            │
            ▼
      AI 复盘（周）──► 计划新版本 ──► 用户确认
```

## 5. 信息架构

```
Tab 1 今日
  ├─ 今日训练卡片（开始 / 休息日）
  ├─ 本周完成度
  ├─ 下次提醒
  └─ 最近训练
Tab 2 计划
  ├─ 当前计划概览（版本、周期）
  ├─ 周视图 / 日详情
  ├─ 编辑计划
  └─ 重新生成
Tab 3 教练
  ├─ 对话
  └─ 周复盘卡片
Tab 4 器械
  ├─ 拍照 / 相册
  ├─ 识别结果
  └─ 动作详情 + 视频
Tab 5 我的
  ├─ 档案与目标
  ├─ 提醒设置
  ├─ 训练历史
  ├─ 隐私与免责
  └─ 订阅（P1）
```

## 6. P0 功能需求

### F1 建档

| 项 | 内容 |
|---|---|
| 必填 | 昵称、性别、年龄、身高、体重、训练经验 |
| 选填 | 三围（胸/腰/臀）、体脂率、伤病与疼痛史、可用器械、每周可练天数、单次时长 |
| 规则 | 年龄 14–70；身高 120–230cm；体重 30–250kg；BMI 自动计算 |
| 安全 | BMI < 18.5 时不允许选择“减脂”目标；未成年人需监护人同意；有伤病时计划需降级并提示咨询医生 |
| 验收 | 3 分钟内可完成；中途退出保留草稿；提交后本地持久化 |

### F2 目标设定

| 项 | 内容 |
|---|---|
| 目标类型 | 减脂 / 增肌 / 重塑体型 / 提升体能 |
| 目标值 | 目标体重、目标腰围、目标日期（至少 4 周后） |
| 规则 | 减重速度上限 0.5kg/周；增重上限 0.25kg/周；目标日期过早时提示“不现实”，并给出建议日期 |
| 验收 | 输入极端值时给出可解释的拦截，而不是直接报错 |

### F3 AI 生成训练计划

| 项 | 内容 |
|---|---|
| 输入 | 档案、目标、器械、每周天数、训练分化、单次时长、伤病 |
| 输出 | 4 周计划；每周 1–5 个训练日；每天 4–7 个动作；含组数、次数、建议重量、休息、RPE |
| 编排规则 | 先按用户选择 1/2/3/4 分化选择模板，再按每周天数循环；同一肌群间隔尽量 ≥48h；具体训练日期可在未来 4 周日历中调整 |
| 安全规则 | 动作必须在动作库内；器械必须匹配；伤病禁忌动作直接剔除；周负荷增幅 ≤10% |
| 失败处理 | 模型超时/JSON 不合法 → 自动降级到规则模板，不向用户报错 |
| 验收 | 20 次生成 ≥19 次通过校验；生成耗时 P95 < 8s；用户可一键重新生成 |

### F4 计划编辑

| 项 | 内容 |
|---|---|
| 能力 | 换动作、增删动作、改组数/次数/重量/休息、改训练日 |
| 动作来源 | 训练日页保留 4 个快速推荐；「完整动作库」直接复用器械页的动作库、搜索、肌群/器械筛选和动作卡片 |
| 约束 | 完整动作库可搜索全部动作；已加入当天的动作不重复展示；删除后当天至少保留 1 个动作 |
| 记忆 | 被用户连续拒绝 2 次的动作为“不喜欢”，后续生成降权 |
| 验收 | 从完整动作库添加后可继续添加，返回训练日立即显示新动作；编辑后立即保存；生成新版本不覆盖旧版本 |

### F5 到点提醒

| 项 | 内容 |
|---|---|
| 设置 | 每个训练日单独设置时间；支持提前 10/30 分钟二次提醒；免打扰时段 |
| 实现 | iOS 17–25 用本地通知（每周重复）；iOS 26+ 用 AlarmKit 做系统级闹钟样式 |
| 限制 | 不承诺突破静音/专注模式（除非 AlarmKit 授权成功）；最多 7 条每周重复通知 |
| 内容 | “今天练胸 + 三头，约 45 分钟”；点击直达今日训练 |
| 验收 | 锁屏状态按时触发；改计划后旧提醒被替换；重启设备后仍有效 |

### F6 训练执行与记录

| 项 | 内容 |
|---|---|
| 流程 | 动作卡片 → 组间记录重量/次数/RPE → 完成组 → 自动休息计时 → 下一动作 |
| 能力 | 跳过动作、替换动作、加组、备注、提前结束 |
| 记录粒度 | 每一组（重量、次数、RPE、是否完成） |
| 离线 | 训练过程完全离线可用，结束后同步 |
| 验收 | 屏幕常亮不熄灭；切后台回来计时不丢；完成训练后首页与历史立即更新 |

### F7 训练历史与 AI 调整

| 项 | 内容 |
|---|---|
| 展示 | 日历/列表、周完成率、总容量、主要动作重量趋势 |
| 调整触发 | 每周一次，或完成 4 次训练后 |
| 调整规则 | 完成率 <60% → 减量 20%；连续 2 次 RPE ≥9 → 降负荷 5–10%；连续 2 周无进步 → 换刺激；停练 ≥2 周 → 按 80% 负荷恢复 |
| 交互 | AI 给出调整理由 → 用户确认 / 拒绝 → 生成新版本 |
| 验收 | 每条调整都能追溯到具体训练数据；用户拒绝后不重复推送同一建议 |

### F8 AI 教练问答

| 项 | 内容 |
|---|---|
| 能力 | 动作要领、计划解释、器械替代、训练不适、饮食基础问题 |
| 上下文 | 当前计划、最近 4 次训练、用户档案、动作库 |
| 安全 | 出现胸痛、眩晕、关节剧痛、怀孕、术后等 → 停止给训练建议，引导就医 |
| 输出 | 流式返回；引用动作库时展示动作卡片 |
| 验收 | 安全问题 100% 触发兜底话术；回答不编造不存在的动作 |

### F9 器械识别

| 项 | 内容 |
|---|---|
| 入口 | 拍照 / 相册 |
| 输出 | Top 3 器械候选 + 置信度 + 对应动作与教学视频 |
| 交互 | 低置信度（<0.6）不自动选定，让用户从候选里确认；可手动搜索 |
| 验收 | 常见 30 种器械 Top-3 命中率 ≥85%；识别失败可降级到手动搜索 |

## 7. P1 / P2

| 优先级 | 功能 | 说明 |
|---|---|---|
| P1 | 饮食计划 + 热量/宏量计算 | 自建食物库，先做“建议 + 手动记录” |
| P1 | Apple 登录、订阅 | StoreKit 2，AI 功能放在订阅后 |
| P1 | HealthKit | 读体重/步数，写训练 |
| P1 | 周报与体型趋势 | 体重、腰围、训练容量 |
| P2 | 美团外卖跳转 | 仅 CPS 活动/搜索链接，无菜单与营养数据 |
| P2 | Apple Watch | 计时、组数记录 |
| P2 | 体型照片对比 | 敏感数据，需单独同意与本地加密 |
| P2 | 社区 / 直播课 | 内容与审核成本高 |

## 8. 明确不做（P0）

- 不做医疗诊断、康复处方、疾病饮食治疗
- 不做孕期/术后/心血管疾病人群的训练计划
- 不做 3D 人体建模与体态诊断
- 不做外卖菜品营养识别（没有可靠数据源）
- 不做社交feed、排行榜
- 不做 Android

## 9. 非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | 冷启动 <2s；计划生成 P95 <8s；训练页操作响应 <100ms |
| 可用性 | 训练过程离线可用；AI 失败不阻断训练 |
| 隐私 | 健康数据境内存储；敏感信息单独同意；支持导出与注销 |
| 无障碍 | 支持动态字体；关键按钮 VoiceOver 可读 |
| 兼容 | iPhone iOS 17+；适配 iPhone SE 到 Pro Max |
| 安全 | 传输 TLS；健康数据加密存储；日志脱敏 |

## 10. 成功指标

| 指标 | 目标（上线 8 周） |
|---|---|
| 建档完成率 | ≥70% |
| 首次训练完成率 | ≥50% |
| 次周留存 | ≥35% |
| 4 周计划完成率 | ≥25% |
| 周活用户人均训练次数 | ≥2.2 |
| AI 对话 7 日使用率 | ≥30% |
| 订阅转化（P1） | ≥3% |

## 11. 开放问题

1. 教学视频自制还是采购？直接影响上线时间与成本。
2. 是否做「私教 1v1 真人服务」？会影响支付合规路径。
3. 目标体型用围度还是参考图？参考图涉及身材焦虑与内容审核。
4. 美团 CPS 主体资质能否下来？拿不到就不做外卖，只做饮食记录。
