# 本地天气、出行提醒与氛围主题

## 目标

- 首页右上角显示当地实时天气。
- 下雨、下雪或降雨概率较高时，发一条本地出行提醒。
- App 主题跟随系统深浅色、清晨/白天/傍晚/夜间和当前天气。
- 雨雪天使用磨砂玻璃卡片和水珠纹理，而不是只换背景色。

## 实现

### 定位

- `Core/Weather/WeatherStore.swift` 使用 `CLLocationManager` 单次获取定位。
- 只在 App 使用期间请求定位，不申请后台定位，不做持续轨迹记录。
- 权限被拒绝时保留上次缓存天气；首页天气胶囊显示“开定位”，详情页提供系统设置入口。
- 坐标在请求天气前四舍五入到 2 位小数（约 1 公里），城市名通过 iOS 地理编码反查。

### 天气

- 数据源：Open-Meteo（`https://api.open-meteo.com/v1/forecast`），无需服务端 API Key。
- 当前天气字段：温度、体感、湿度、风速、云量、降水、天气代码、昼夜。
- 日数据：最高/最低温、降雨概率。
- 缓存：`UserDefaults` 保存最后一次成功快照，离线或请求失败时继续显示。
- 刷新：启动、回到前台、每 5 分钟检查一次；成功数据 15 分钟内不重复请求。
- 请求失败不阻塞首页，只在天气详情页显示错误和重试。

### 出行提醒

- 通知能力复用 `NotificationScheduler`，使用本地通知，不依赖 APNs 或服务端。
- 满足任一条件触发：当前有雨/雪、雷雨、或当日降雨概率 ≥ 60%。
- 每个自然日最多提醒一次，按 `yyyy-MM-dd` 去重，避免反复打扰。
- 22:00–07:00 不主动发天气提醒，避免夜间打扰。
- 若系统通知未开启，天气详情和设置页会显示权限状态和系统设置入口。
- 当前限制：提醒在 App 刷新天气时检查；关闭 App 后没有后台常驻定位，因此不会做后台天气轮询。

### 主题

- `Core/Design/Theme.swift` 使用动态 `UIColor` 语义色，随 iOS 浅色/深色模式切换。
- `Core/Design/Atmosphere.swift` 根据天气和时段生成背景、强调色、雨雪强度。
- 时段：清晨 05:00–07:59、白天 08:00–16:59、傍晚 17:00–19:59、夜间其余时间。
- 天气：晴、多云、阴/雾、雨、雪、雷雨有不同背景；系统浅色下使用柔和浅色背景和深色文字，避免纯白页面和低对比度。
- 主题每 5 分钟更新一次时段，切换系统外观或天气后自动刷新。
- 雨雪天 `CardModifier` 切换为 `.ultraThinMaterial` 磨砂卡片，并叠加静态水珠纹理；顶层有极轻的水珠层，不拦截交互。
- 所有水珠纹理使用静态 `Canvas`，不做逐帧动画；减弱动态效果时只保留静态纹理。

## 测试清单

- 首次进入：允许定位 → 首页出现温度；拒绝定位 → 显示开定位入口。
- 断网/飞行模式：有缓存显示缓存，无缓存显示重试。
- 系统浅色/深色切换：文字、卡片、导航栏和天气胶囊仍可读。
- 清晨/白天/傍晚/夜间切换背景。
- 雨天：卡片磨砂、水珠纹理、首页出行提示。
- 通知权限开启/关闭/拒绝三种状态。
- 同一天多次刷新只发一条天气提醒。
- 关闭训练提醒不会删除天气提醒设置。
