# iOS 同步最新 Web 计划能力

> 2026-10 · 对应 Web Preview 的计划、首页、生理期、身体数据与教练拍照变更。

## 已同步

### 计划

- 训练分化：`1分化 / 3分化 / 5分化`，保存资料后会按新分化、频率、时长、经验和器械重新生成计划。
- 每周训练 `1–7` 天；单次时长 `30 / 45 / 60 / 90 / 120` 分钟。
- 计划标题包含目标、分化和每周训练次数。
- 动作生成严格使用用户选中的器械；器械库里的额外动作也必须属于已选器械。
- `PlanDay.date` 支持真实训练日期；计划页、首页今日卡和训练日历按日期同步。
- 新增「训练日期」页面：未来 4 周、每周目标训练日数、4×7 日期板；保存后映射动作并更新日历/首页。
- 新增独立「数据复盘」页面：本周/本月/今年、6 项 KPI、训练/饮食摘要、最近训练；计划页只保留摘要入口。
- 新增「经期」页面：女性用户选择区间，支持轻重量训练 / 直接休息；计划日历显示经期标记，今日页显示经期状态。

### 首页

- 新增目标卡：目标体重、当前体重、完成百分比、距离目标、目标日期、腰围/体脂目标。
- 新增每日身体数据打卡入口。
- 训练卡与饮食卡同级展示；休息日饮食/恢复优先。
- 经期轻量版自动减少 1 组、负重约 80%；直接休息时隐藏力量训练入口。
- 目标进度使用身体指标时间线，不再只看资料里的单次体重。

### 身体数据

- 身体打卡字段统一为：体重、体脂率、腰围。
- 打卡写入 `BodyMetric` 时间线，并同步资料体重/体脂/腰围。
- 资料编辑补充体脂率、臂围、大腿围；保存时追加当天身体指标。
- 支持关闭 / 每周 / 每两周 / 每月提醒；到日期打开今日页自动弹出。

### 档案与设置

- 保存按钮固定在导航栏右上角，不需要滚到底部。
- 修改目标、分化、频率、时长、经验或器械会自动重排计划，并提示手动训练日会被覆盖。
- 可用器械可以为空但不能保存；至少选择一种能生成动作的器械。
- 设置页新增身体数据提醒配置。

### 教练

- 输入栏新增相机按钮，复用 `PhotoCaptureView`。
- 照片消息显示在对话气泡中，并追加教练追问。
- 照片仅用于本次对话；远程视觉接口后续接入。

## 兼容与限制

- 旧本地 JSON 状态通过 `decodeIfPresent` 兼容新增字段；旧计划没有 `date` 时继续按 `createdAt + week/weekday` 计算。
- 远程 FastAPI 计划生成接口目前不携带 `split`，iOS 本地规则已支持分化；远程模式仍以服务端返回结构为准。
- 图片消息目前本地模拟教练回复；接入真实视觉接口时替换 `CoachPhotoStore`。
- iOS 构建通过 GitHub Actions 的 `iOS Build` 工作流验证；本机 Windows 不能直接跑 Xcode。
