# 协议与隐私文档（2026-11）

## 文档位置

App 内四份文本统一由 `ios/FitAI/Features/Legal/LegalDocuments.swift` 提供：

| 文档 | 入口 |
| --- | --- |
| 用户协议 | 登录页同意区、我的 → 协议与数据、Pro 订阅页 |
| 隐私政策 | 登录页同意区、我的 → 协议与数据、Pro 订阅页 |
| 健康免责声明 | 登录页同意区、我的 → 协议与数据、Pro 订阅页 |
| 生成式 AI 服务说明 | 我的 → 协议与数据 |

`LegalDocumentView` 仍位于 `LoginView.swift`，只负责渲染；文本、版本、运营者和联系方式集中在 `LegalDocuments.swift`。

## 已按代码实际情况写入的内容

- 账号：手机号、密码、Apple 登录；微信/QQ 以“如启用”表述。
- 身体与训练：档案、伤病、器械、计划、组数/次数/重量/RPE、训练心得。
- 饮食：餐单、热量与三大营养素、食物记录；估算值与过敏原边界。
- AI：DeepSeek 文本与图片推理；发送档案摘要、最近对话和压缩图片；原视频不上传，只发关键帧。
- 照片：服务端不落原图；聊天仅保存文字摘要和 `[图片]` 标记；设备本地保留聊天图片和进展照片。
- HealthKit：读取体重/身高/体脂/训练，写入完成的训练。
- 位置：仅使用期间、约 1 公里精度；坐标发给 Open-Meteo，城市名由 Apple 逆地理编码；不经过 FitAI 后端。
- 通知：仅本地通知；已确认不做 APNs 远程推送。
- 订阅：Apple IAP、自动续期、取消方式；不接触支付卡信息。
- 注销：15 天冷静期；期满删除或匿名化；设备进展照片和系统备份需手动删除。
- 第三方：Apple、DeepSeek、短信服务商、Open-Meteo、云与数据库服务商。
- 微信/QQ 登录已在 UI 隐藏；美团外卖入口已删除。
- 未接入广告、统计、崩溃上报、跨 App 追踪 SDK。

## 正式上线前必须补齐

1. **运营者法定信息**：当前使用“练途 FitAI（个人开发者）”和 `wjk0759@163.com`。正式版应替换为真实姓名/主体名称、可长期使用的客服邮箱，必要时补充地址。
2. **ICP 备案 / App 备案 / 公安联网备案**：隐私政策目前没有写备案号；取得后应补入文末。
3. **生成式 AI 备案/登记**：AI 说明已明确“内测版本、上线前完成备案并公示”；未完成前不要在中国大陆正式渠道开放 AI 功能。
4. **短信服务商**：当前后端默认 `SMS_PROVIDER=dev`，仅 `APP_ENV=dev` 时回传开发验证码；正式版必须接入短信服务并更新“共享与委托处理”。
5. **生产部署与 TLS**：正式环境需使用境内服务器、HTTPS/TLS、受控数据库；隐私政策已按正式环境描述。
6. **注销后的物理删除**：`DELETE /me` 仍是软删除 + 15 天冷静期；`RetentionService` 已自动清理过期用户、短信码、认证事件、AI job 等，上线前需在预发库验证一次批处理。
7. **PrivacyInfo.xcprivacy**：已补定位、聊天内容、姓名/手机号、照片 linked 和 UserDefaults 理由 API；仍需在 App Store Connect 隐私标签中逐项核对。
8. **投诉与客服渠道**：当前只有邮箱，没有 App 内反馈/举报入口；若保留“15 个工作日回复”承诺，需要有人实际处理。
9. **微信/QQ/美团**：微信/QQ 登录入口已隐藏，后端 OAuth 能力保留；美团外卖入口与后端接口已删除。不要在没有产品决策的情况下恢复。
10. **服务端 Pro 校验**：目前 Pro 仅客户端判断，后端 AI 接口没有权益校验；这不是文案问题，但会影响订阅条款的实际执行。

## 维护规则

- 改动数据流（新增第三方、上传原图、接入推送/统计、改变保留期限）时，同步更新 `LegalDocuments.swift` 和 `PrivacyInfo.xcprivacy`。
- 更新日期统一使用 `LegalMeta.updatedAt`。
- 不要在协议里写“数据一定存储在境内”“图片 30 天内删除”等代码尚未保证的承诺。
