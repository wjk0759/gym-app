# 13 · 器械 Tab：动作选择与器械识别

这版按参考布局重做器械 Tab，只动器械模块，不改首页、计划和底部导航。全局流体间距、安全区和大屏可读宽度规范见 `docs/17-responsive-layout.md`。

## 页面结构

```text
器械 Tab（不再放大标题）
├── 吸顶工具区（滚动时平滑收拢为玻璃工具条）
│   ├── 搜索动作 + 右侧拍照识别
│   ├── 右侧器械库入口
│   └── 器械过滤：全部 / 已添加 / 哑铃 / 徒手 / 固定器械 / 绳索 / 杠铃 / 壶铃 / 弹力带
├── 动作库标题 + 当前动作数量 + 详情/多选提示
├── 搜索时跨全部动作，暂不按当前分类过滤；分类高亮收起
├── 点分类会清空搜索，回到该肌群 / 器械
├── 左侧竖向肌群栏：全部 / 胸 / 背 / 腿 / 臀 / 肩 / 手臂 / 核心 / 有氧
│   └── 固定在卡片区左侧，卡片滚动时保持不动
├── 右侧两列动作卡片
│   ├── 讲解标记
│   ├── 动作名称、肌群、器械
│   └── 选中勾选
└── 左下角：已选动作浮动入口（哑铃图标 + 数量）
    └── 向上弹出已选动作气泡
        ├── 已选动作长列表 / 单个移除 / 清空
        ├── 制作训练计划 → 安排训练编排页
        └── 加入我的器械库
```

- 滚动时吸顶的是搜索 + 器械分类工具区，不再吸顶页面大标题。
- 滚动后工具区只渐变玻璃背景，不改变自身高度，避免吸附位置抖动。
- 左侧肌群栏固定在卡片区左侧；只有右侧动作卡片滚动。
- 左下角入口只保留哑铃图标和数量角标，不显示“已选动作”文字。
- 已选动作气泡列表独立滚动；列表内容不足或滚到边界时，拖拽/滚轮不会穿透到底层动作页。
- 顶部保留「器械库」入口，原有已保存器械、添加器械、删除器械功能不丢。
- 动作卡片主体点击进入动作详情；右上角独立的 +/✓ 按钮负责多选，避免导航和勾选互相抢占。
- 卡片底部保留展开箭头作为详情提示；多选按钮始终可见，未选时为空心 +，已选时为主色 ✓ 并高亮卡片描边。
- 点卡片看详情，右上角 + 多选；返回到器械 Tab 时保留搜索、肌群和器械筛选。
- 训练记录编辑页的「添加动作」复用器械页动作库选择器：搜索、肌群筛选、器械筛选和动作卡完全一致，不再弹出手动输入动作名的 prompt。
- 计划日历「编辑训练日」里的「从动作库添加动作」同样复用 `EquipmentPickerView(onSelect:)` / Web `planExercisePicker`，不再维护单独的计划动作选择页。
- 动作详情的富内容直接复用器械库详情页：视频、动作轨迹、多角度、要点、训练肌群；动作预览时隐藏置顶和从器械库删除。训练数据已迁移到计划页。
- 不再维护旧的简版动作详情页面；器械卡、器械识别和器械详情共用同一套详情实现。
- 左下角是健身语境下的「已选动作」入口；图标使用哑铃和数量，不出现购买、结算等文案。
- 已选动作气泡从底部向上展开，列表较长时可滚动，里面完成移除、清空和下一步选择。
- 「制作训练计划」先进入编排页，确认动作顺序、组数、次数、重量和休息后再开始；不修改当前长期计划。「加入我的器械库」批量写入未保存的动作，并自动跳过已在库动作。
- 识别入口会打开「器械识别」页。

## 视觉规范

- 工具区：搜索框 48pt 高、圆角 15pt，拍照识别 34pt，器械库 48pt；三者共用描边和玻璃质感。
- 抬头：卡片区上方增加「动作库 + 数量」轻量标题，右侧只保留「详情 / 多选」或「加入训练日」一句提示。
- 筛选：器械标签高约 30pt、字号 11pt、圆角 9pt；肌群栏宽 56pt，选中项使用主色 14% 底色和 8pt 圆角。
- 搜索态：分类高亮暂时收起，顶部提示「全库搜索中 · 点分类可退出搜索」；点分类会清空搜索。
- 卡片：双列、间距 9pt、圆角 17pt，封面高 102pt；名称 13.5pt、元信息 10pt。
- 图标：卡片统一使用动作肌群线性图标，不再混用彩色 emoji；肌群图标和左侧筛选一一对应。
- 选中：右上角 30pt 独立按钮，未选为「+」，已选为实心主色「✓」；卡片同时显示细主色描边和轻微主色光晕。
- 计划模式：卡片点击直接加入训练日，右上角使用弱化的「+」提示，不显示多选按钮。
- 响应式：320 / 390 / 430 宽度下不横向溢出；320 下肌群栏收至 52pt，封面收至 92pt。

## 器械识别流程

1. 点搜索栏右侧「识别」
2. 直接进入相机拍摄页
   - 左上角退出按钮
   - 右上角相册入口
   - 底部拍照按钮
3. 拍照或从相册选图后立刻识别
4. 识别完成才进入结果页
   - 照片缩略图
   - 重新拍照
   - 匹配器械候选数量
   - 未识别时的空状态与拍摄建议
   - 候选可加入已选动作
5. 用户退出相机且没有照片时，直接关闭识别流程，不进入空白结果页

## 代码复用与模块拆分

- `EquipmentRecognitionService`
  - 统一“远程视觉模型优先、失败回退本地识别”的逻辑
  - 识别页、器械库、器械选择器共用
- `EquipmentRecognitionView`
  - 只负责照片、候选、保存/加入已选交互
  - 器械选择器和器械库只传入回调，不再各自实现识别流程
- `PhotoCaptureView`（原 `EquipmentCameraView`，现为饮食 / 器械 / 体型共用）
  - 相机优先的拍摄页，复用同一套退出/相册/拍照交互
  - 相机不可用或权限拒绝时保留相册入口
- `EquipmentSelectionPanelView`
  - 左下角已选动作气泡的唯一实现
  - 负责列表、移除、清空和两个出口按钮
- `AppStore.addExercisesToEquipmentLibrary`
  - 统一批量写入器械库，自动去重
  - 选择器、器械库搜索共用同一套写入逻辑
- `EquipmentItemDetailView(exercise:)`
  - 动作卡、器械识别和器械详情共用同一套富内容页面
  - 动作预览态隐藏置顶和删除，避免执行器械库条目专属操作
- 网页预览删除旧的识别页、旧添加入口和简版动作详情，识别统一走“相机 → 结果页”流程

## 器械库重设计

- 顶部轻量返回头，不再使用大标题。
- 概览卡集中展示器械数量，并把「计划优先使用」开关放进同一张卡。
- 搜索框与拍照添加入口合并成一条工具行。
- 器械从双列大图卡改为单列信息行：缩略图、名称、肌群/器械类型、视频状态、详情箭头。
- 支持按器械名称、肌群、器械类型即时筛选；空库和无搜索结果分别有空状态。
- 器械行支持左滑露出删除；删除前二次确认，删除后停留在器械库并保留当前搜索条件。
- 保留手动添加、拍照/相册添加、详情、计划优先使用开关。

## 器械详情重构

详情页参考「动作学习」信息层级，改成富内容的长页，而不是只有名称、视频和删除按钮。

```text
器械详情
├── 顶部快捷卡：器械名 + 要点 / 数据 / 置顶
├── 动作学习预览：眉题、大标题、动作说明、肌群/器械/视频状态
├── 01 视频讲解：有官方视频时直接播放；没有时显示准备中，不伪造视频
├── 02 动作轨迹：浅色轨迹示意板，说明起始位置、方向和还原速度
├── 03 多角度示范：示范素材准备中，用占位角度卡说明后续内容
├── 04 动作要点：动作库说明拆成蓝色编号要点 + 器械备注提示
├── 05 训练肌群：正面/背面精细解剖示意、目标部位聚光、主要肌群和协同肌群
├── 问教练：把当前动作交给 AI 教练继续解释
└── 从器械库删除
```

- 顶部「要点」滚动到动作要点；「数据」进入计划页的动作训练数据。
- 「置顶」使用本地持久化；置顶的器械在器械库排在最前，并在列表行显示置顶图标。
- 视频、3D 动图、多角度示范没有授权素材时不展示假内容，统一显示「准备中」并保留版式。
- 训练数据已从动作详情迁移到计划页「动作训练数据」，动作详情不再保留 06 模块。
- 动作数据按动作 slug 从本地训练记录汇总；没有记录时显示空状态，不虚构数字。
- 折线图横轴按每次训练的实际时间定位，不是按训练次数等距排列。
- 汇总口径：容量记录为所选周期累计容量，重量记录为单组最大重量，1RM 预测为 Epley 公式估算的周期最高值。
- 组数、最大重量、1RM 预测都可切换为折线图；切换周期或指标不会重置页面滚动位置。
- 自定义周期可选择开始/结束日期；开始晚于结束时显示错误并清空图表，不展示误导数据。
- 训练肌群图使用精细正面/背面线稿，按主要肌群切换 8 套高亮变体；重点为青绿色、辅助为蓝绿色，并由图上标签与图例说明。
- 每套图都包含“重点 / 辅助”及正面/背面标识，避免只靠颜色猜测训练部位。
- 解剖素材来源与授权见 `docs/15-anatomy-asset.md`；详情页保留小型署名。
- 删除仍走二次确认，删除后关闭详情并停留在器械库。
- 原生实现：`Features/Equipment/EquipmentDetailView.swift`；Web 预览：`equipmentItemScreen()` 与 `.detail-*` 样式。

## 与旧版器械库的关系

旧器械库仍然存在：

- 器械 Tab 右上角 → 器械库
- 器械库仍可搜索、拍照、相册添加
- 删除器械仍会影响计划生成优先级

这样既能提供动作选择器，也没有牺牲已有的器械管理能力。

## 验收

- 网页预览走通动作多选、左下角已选动作气泡、移除/清空
- 网页预览走通「制作训练计划」与「加入我的器械库」两条出口
- 搜索时跨全部动作，不受肌群/器械分类影响
- 搜索框支持一键清空，结果数量随搜索和筛选同步更新
- 搜索、筛选、肌群和卡片在 280 / 320 / 375 / 390 / 430 宽度及横屏下不横向溢出
- 器械下拉标签、肌群栏、卡片图标和选中态使用统一尺寸与描边规范
- 网页预览走通器械识别空状态、模拟拍照、识别结果加入已选
- 网页预览支持鼠标拖拽滚动、触摸滑动和滚轮滚动
- 网页预览可打开器械详情，快捷入口能滚动到要点；「数据」跳到计划页动作训练数据
- 器械详情无横向溢出；动作详情不再包含训练数据模块
- 计划页动作训练数据可切换 7 天 / 30 天 / 90 天 / 全部 / 自定义周期
- 容量、组数、最大重量、1RM 预测四个指标都能切换为折线图
- 自定义周期开始晚于结束时出现错误提示且不展示误导数据
- 训练肌群图加载精细正面/背面解剖示意图，目标肌群有聚光与描边
- 可置顶器械，返回器械库后置顶项排在最前并显示置顶图标
- 制作训练计划先进入编排页，确认后才会开始训练
- 今日页「开始训练」同样先进入同一编排页，使用计划快照，不修改长期计划
- 训练中可调整当前动作目标组数、次数、重量和休息，进度即时更新
- 不修改后端接口
