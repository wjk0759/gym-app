# 13 · 器械 Tab：动作选择与器械识别

这版按参考布局重做器械 Tab，只动器械模块，不改首页、计划和底部导航。

## 页面结构

```text
器械 Tab（不再放大标题）
├── 吸顶工具区（滚动时平滑收拢为玻璃工具条）
│   ├── 搜索动作 + 右侧拍照识别
│   ├── 右侧器械库入口
│   └── 器械过滤：全部 / 已添加 / 哑铃 / 徒手 / 固定器械 / 绳索 / 杠铃 / 壶铃 / 弹力带
├── 搜索时跨全部动作，不按当前肌群/器械分类过滤
├── 左侧竖向肌群栏：全部 / 胸 / 背 / 腿 / 臀 / 肩 / 手臂 / 核心 / 有氧
│   └── 固定在卡片区左侧，卡片滚动时保持不动
├── 右侧两列动作卡片
│   ├── 讲解标记
│   ├── 动作名称、肌群、器械
│   └── 选中勾选
└── 左下角：已选动作浮动入口（哑铃图标 + 数量）
    └── 向上弹出已选动作气泡
        ├── 已选动作长列表 / 单个移除 / 清空
        ├── 制作训练计划
        └── 加入我的器械库
```

- 滚动时吸顶的是搜索 + 器械分类工具区，不再吸顶页面大标题。
- 滚动后工具区只渐变玻璃背景，不改变自身高度，避免吸附位置抖动。
- 左侧肌群栏固定在卡片区左侧；只有右侧动作卡片滚动。
- 左下角入口只保留哑铃图标和数量角标，不显示“已选动作”文字。
- 已选动作气泡列表独立滚动；列表内容不足或滚到边界时，拖拽/滚轮不会穿透到底层动作页。
- 顶部保留「器械库」入口，原有已保存器械、添加器械、删除器械功能不丢。
- 点动作卡片可多选；再次点击取消。
- 左下角是健身语境下的「已选动作」入口；图标使用哑铃和数量，不出现购买、结算等文案。
- 已选动作气泡从底部向上展开，列表较长时可滚动，里面完成移除、清空和下一步选择。
- 「制作训练计划」生成一次自选训练，不修改当前长期计划；「加入我的器械库」批量写入未保存的动作，并自动跳过已在库动作。
- 识别入口会打开「器械识别」页。

## 器械识别流程

1. 点搜索栏右侧「识别」
2. 直接进入相机拍摄页
   - 左上角退出按钮
   - 右上角相册入口
   - 底部拍照按钮
3. 拍照或从相册选图后立刻识别
4. 识别完成才进入结果页
   - 照片缩略图
   - 重新拍照
   - 匹配器械候选数量
   - 未识别时的空状态与拍摄建议
   - 候选可加入已选动作
5. 用户退出相机且没有照片时，直接关闭识别流程，不进入空白结果页

## 代码复用与模块拆分

- `EquipmentRecognitionService`
  - 统一“远程视觉模型优先、失败回退本地识别”的逻辑
  - 识别页、器械库、器械选择器共用
- `EquipmentRecognitionView`
  - 只负责照片、候选、保存/加入已选交互
  - 器械选择器和器械库只传入回调，不再各自实现识别流程
- `EquipmentCameraView`
  - 相机优先的拍摄页，复用同一套退出/相册/拍照交互
  - 相机不可用或权限拒绝时保留相册入口
- `EquipmentSelectionPanelView`
  - 左下角已选动作气泡的唯一实现
  - 负责列表、移除、清空和两个出口按钮
- `AppStore.addExercisesToEquipmentLibrary`
  - 统一批量写入器械库，自动去重
  - 选择器、器械库搜索共用同一套写入逻辑
- `ExerciseDetailView`
  - 从识别文件拆出，独立负责动作详情和教学视频
- 网页预览删除旧的识别页和旧添加入口，识别统一走“相机 → 结果页”流程

## 器械库重设计

- 顶部轻量返回头，不再使用大标题。
- 概览卡集中展示器械数量，并把「计划优先使用」开关放进同一张卡。
- 搜索框与拍照添加入口合并成一条工具行。
- 器械从双列大图卡改为单列信息行：缩略图、名称、肌群/器械类型、视频状态、详情箭头。
- 支持按器械名称、肌群、器械类型即时筛选；空库和无搜索结果分别有空状态。
- 器械行支持左滑露出删除；删除前二次确认，删除后停留在器械库并保留当前搜索条件。
- 保留手动添加、拍照/相册添加、详情、计划优先使用开关。

## 器械详情重构

详情页参考「动作学习」信息层级，改成富内容的长页，而不是只有名称、视频和删除按钮。

```text
器械详情
├── 顶部快捷卡：器械名 + 要点 / 历史 / 图表 / 置顶
├── 动作学习预览：眉题、大标题、动作说明、肌群/器械/视频状态
├── 01 视频讲解：有官方视频时直接播放；没有时显示准备中，不伪造视频
├── 02 动作轨迹：浅色轨迹示意板，说明起始位置、方向和还原速度
├── 03 多角度示范：示范素材准备中，用占位角度卡说明后续内容
├── 04 动作要点：动作库说明拆成蓝色编号要点 + 器械备注提示
├── 05 训练肌群：正面/背面精细解剖示意、目标部位聚光、主要肌群和协同肌群
├── 06 训练数据：容量/重量/1RM 汇总 + 折线趋势
│   ├── 指标：容量 / 组数 / 最大重量 / 1RM 预测
│   ├── 周期：7 天 / 30 天 / 90 天 / 全部 / 自定义日期
│   └── 每个点对应一次含该动作的训练记录
├── 问教练：把当前动作交给 AI 教练继续解释
└── 从器械库删除
```

- 顶部「要点」滚动到动作要点，「历史」「图表」滚动到训练数据。
- 「置顶」使用本地持久化；置顶的器械在器械库排在最前，并在列表行显示置顶图标。
- 视频、3D 动图、多角度示范没有授权素材时不展示假内容，统一显示「准备中」并保留版式。
- 训练数据按动作 slug 从本地训练记录汇总；没有记录时显示空状态，不虚构数字。
- 折线图横轴按每次训练的实际时间定位，不是按训练次数等距排列。
- 汇总口径：容量记录为所选周期累计容量，重量记录为单组最大重量，1RM 预测为 Epley 公式估算的周期最高值。
- 组数、最大重量、1RM 预测都可切换为折线图；切换周期或指标不会重置详情页滚动位置。
- 自定义周期可选择开始/结束日期；开始晚于结束时显示错误并清空图表，不展示误导数据。
- 训练肌群图使用精细正面/背面线稿，按主要肌群切换 8 套高亮变体；重点为青绿色、辅助为蓝绿色，并由图上标签与图例说明。
- 每套图都包含“重点 / 辅助”及正面/背面标识，避免只靠颜色猜测训练部位。
- 解剖素材来源与授权见 `docs/15-anatomy-asset.md`；详情页保留小型署名。
- 删除仍走二次确认，删除后关闭详情并停留在器械库。
- 原生实现：`Features/Equipment/EquipmentDetailView.swift`；Web 预览：`equipmentItemScreen()` 与 `.detail-*` 样式。

## 与旧版器械库的关系

旧器械库仍然存在：

- 器械 Tab 右上角 → 器械库
- 器械库仍可搜索、拍照、相册添加
- 删除器械仍会影响计划生成优先级

这样既能提供动作选择器，也没有牺牲已有的器械管理能力。

## 验收

- 网页预览走通动作多选、左下角已选动作气泡、移除/清空
- 网页预览走通「制作训练计划」与「加入我的器械库」两条出口
- 搜索时跨全部动作，不受肌群/器械分类影响
- 网页预览走通器械识别空状态、模拟拍照、识别结果加入已选
- 网页预览支持鼠标拖拽滚动、触摸滑动和滚轮滚动
- 网页预览可打开器械详情，快捷入口能滚动到要点和数据区
- 器械详情无横向溢出；训练数据无记录时显示空状态
- 训练数据可在 7 天 / 30 天 / 90 天 / 全部 / 自定义周期之间切换
- 容量、组数、最大重量、1RM 预测四个指标都能切换为折线图
- 自定义周期开始晚于结束时出现错误提示且不展示误导数据
- 训练肌群图加载精细正面/背面解剖示意图，目标肌群有聚光与描边
- 可置顶器械，返回器械库后置顶项排在最前并显示置顶图标
- 不修改后端接口
