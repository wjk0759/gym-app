# 13 · 器械 Tab：动作选择与器械识别

这版按参考布局重做器械 Tab，只动器械模块，不改首页、计划和底部导航。

## 页面结构

```text
器械 Tab
├── 已选择动作
│   └── 动作 chips（可单个移除）
├── 搜索动作 + 识别入口
├── 器械过滤：全部 / 已添加 / 哑铃 / 徒手 / 固定器械 / 绳索 / 杠铃 / 壶铃 / 弹力带
├── 左侧肌群栏：全部 / 胸 / 背 / 腿 / 臀 / 肩 / 手臂 / 核心 / 有氧
├── 两列动作卡片
│   ├── 讲解标记
│   ├── 动作名称、肌群、器械
│   └── 选中勾选
└── 底部操作：清空 / 组合 N 个动作
```

- 右上角保留「器械库」入口，原有已保存器械、添加器械、删除器械功能不丢。
- 点动作卡片可多选；再次点击取消。
- 点「组合」会把选中动作组成一次临时训练，直接进入训练记录流程。
- 识别入口会打开「器械识别」页。

## 器械识别页

- 照片识别卡片
- 重新拍照 / 相册
- 匹配器械候选数量
- 未识别时的空状态与拍摄建议
- 识别候选可加入已选动作
- 原有器械识别服务与本地 Mock 逻辑保留

## 代码复用与模块拆分

- `EquipmentRecognitionService`
  - 统一“远程视觉模型优先、失败回退本地识别”的逻辑
  - 识别页、器械库、器械选择器共用
- `EquipmentRecognitionView`
  - 只负责照片、候选、保存/加入已选交互
  - 器械选择器和器械库只传入回调，不再各自实现识别流程
- `ExerciseDetailView`
  - 从识别文件拆出，独立负责动作详情和教学视频
- 网页预览删除旧的识别页和旧添加入口，识别统一走 `equipmentRecognitionScreen`

## 与旧版器械库的关系

旧器械库仍然存在：

- 器械 Tab 右上角 → 器械库
- 器械库仍可搜索、拍照、相册添加
- 删除器械仍会影响计划生成优先级

这样既能提供动作选择器，也没有牺牲已有的器械管理能力。

- 网页预览走通器械识别空状态、模拟拍照、识别结果加入已选
