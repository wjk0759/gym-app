# 小字注释清理（2026-11）

## 分级标准

| 等级 | 定义 | 处理 |
| --- | --- | --- |
| 必要 | 医疗/隐私/安全声明、订阅条款、错误提示、操作约束、数据口径 | 保留 |
| 可要可不要 | 能帮助理解后果或恢复操作，但删掉也不影响完成任务 | 保留 |
| 无所谓 | 重复说明、显而易见的点按提示、状态复述 | 删除 |
| 非必要 | 营销文案、设计/技术实现说明、内部备注、纯鼓励语 | 删除 |

本轮共删除 45 处 `Text` 注释，改写了 3 条过长的说明，涉及 23 个文件。

## 删除清单

### 首页 / 今日

- 训练、饮食、动作点评，直接跟教练说
- 计划不会因为忙就作废。可以顺延，也可以明确跳过
- 展开
- 今日已打卡 · 进度已更新 / 今天记录一次，进度自动更新

### 饮食

- 按目标热量估算；也可以让 AI 按档案重排 / AI 按你的档案、体型和目标排餐
- 吃过什么就记什么，不用给食物打分
- 根据你的档案、体型和目标生成，可随时重新生成
- 可以继续搜索添加，全部记好后点右上角「完成」
- 记录是为了了解，不是为了给食物打分
- 如果吃的是一整碗/一整份，填整份重量。螺蛳粉通常约 500–700g
- 这些数值会按“这一份”换算成每 100g 保存
- 没有“好食物/坏食物”
- 螺蛳粉、火锅、奶茶也可以识别，这里只估算热量
- 勾选实际吃下的食物，份量可以调

### 教练 / 发现

- 点开每天看餐单，点菜名查看家常做法
- 训练、饮食、恢复、计划都能直接说
- 识别器械后，直接给出动作、目标肌群和替代方案
- 拍一张，或发一段视频，让教练指出下一组最该改的一点

### 器械

- 器械库会作为 AI 生成计划的可用来源；删除器械不会影响历史训练记录
- 教学视频与 AI 计划会优先读取这里
- 输入器械或动作名称，选中后直接加入器械库，并自动带上教学视频
- 点卡片看详情 · ⊕ 多选
- 起始位置、发力方向和还原速度，比盲目加重量更重要
- 让教练结合你的计划，解释起始位置、发力顺序和替代动作

### 计划 / 进度

- 点一天，翻到那页
- 计划不是合同。时间、恢复或疼痛有变化，先和教练说
- 平均每日时长 = 周期内训练总分钟 ÷ 周期天数
- 按周选择，点一下切换
- 稳定比一次练狠更重要
- 不用完美，先记一天 / 记录本身就是反馈
- 看动作、容量和 RPE 的详细变化
- 拖动中间的分隔线，看同一角度的变化

### 训练

- 点数字输入 · 长按连续调
- 练完一次，这里就会多一页

### 我的 / 设置 / 登录

- AI 计划、教练与器械识别
- 拍一张照片，获取训练重点建议
- 所有 Pro 功能已解锁
- 仅 Debug 生效，用于在没有 StoreKit 商品时预览 DeepSeek
- 本页为应用内公示文本，正式上线版本将由法务复核

### 引导 / 经期 / 天气

- 不是体检，是决定接下来 4 周怎么练
- 有伤病就点下面的选项，会自动取消“没有任何伤病”
- 如果愿意，也可以改成推荐目标
- 经期安排只会在女性用户的计划和记录页中出现
- 提醒会在 App 刷新天气时检查；关闭 App 后不会持续获取位置
- 界面会跟随深浅色和天气自动调整；雨天使用克制的背景雨线

## 保留的关键说明

- 医疗免责声明、孕期/术后/慢病人群提示、过敏原提示
- 照片、视频、位置、健康数据的上传范围与保存方式
- 伤病与疼痛的安全拦截、经期强度调整
- 订阅自动续期、Apple ID 付款与取消方式
- 日期错误、离线、相机失败等错误提示
- “至少选一种器械”“最多选 2 个重点部位”等操作约束
- 空状态下的恢复路径与下一步入口
