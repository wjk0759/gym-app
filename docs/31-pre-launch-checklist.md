# 31 · 上线前待办清单

按「谁能做」分三档，这样你能一眼看出哪些我能直接替你做完、哪些卡在你要先给的东西、哪些只能你本人办。

- **A = 我能独立替你完成**（纯技术，我直接做完，你在场验收即可）
- **B = 我做的、但需要你先给东西**（卡在账号/密钥/素材/决策，你不给我就动不了）
- **C = 只能你本人做**（花钱、签约、法务、资质主体，我无法代劳）

> ⚠️ = 上线阻断项。

---

### 测试 / 收尾
- [ ] 真机验收配合、回归测试、性能安全自测
- [ ] 提交整理代码、合并分支（testing → main）

## 一句话速记

- 你只要管：**钱、账号、资质、授权、法务、最终拍板**（C + B 的「给」那一列）。
- 剩下的**代码、清洗、部署配置、接入、测试、文档**，我都能替你做（A + B 的「我负责」那一列），你把我卡的东西给齐就行。
