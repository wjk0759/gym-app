# 21 · AI 教练主导的计划调整

## 产品原则

计划调整不是「点一下按钮，系统自动改动作」。正确流程是先让 AI 教练理解用户的真实问题：

```text
当前计划 / 首页 AI 卡片
  → 跳转 AI 教练
  → 教练询问：最近训练遇到了什么？
  → 用户描述问题（时间 / 恢复 / 疼痛 / 平台 / 计划太满 / 动力）
  → 教练追问缺失细节
  → 教练给出可解释的调整方案
  → 用户确认应用
  → 写回计划版本
```

- 调整前不直接修改计划。
- 用户取消时计划保持不变。
- 方案必须引用用户说过的内容，并说明为什么这样调整。
- 选中方案后仍可继续补充，AI 会重新计算方案。
- 调整完成后保留对话记录，并提供「查看更新后的计划」。

## 对话阶段

```text
01 说明问题
02 补充细节
03 确认方案
```

### 01 说明问题

首次进入调整模式，AI 先问最近训练中最困扰用户的是什么，并提供快捷选项：

- 时间不够，练不完
- 恢复不过来，总是累
- 某个动作会疼
- 重量卡住不进步
- 计划太满，坚持不了

同时允许自由输入具体训练场景。

### 02 补充细节

根据问题类型追问必要信息：

| 问题 | 追问 |
| --- | --- |
| 疼痛 | 部位、动作、疼痛分数、是否肿胀 / 麻木 / 刺痛 |
| 时间 | 每次实际时长、每周可训练天数 |
| 恢复 | 睡眠、酸痛持续时间、疲劳类型 |
| 平台 | 卡住的动作、持续时间、是否力竭 |
| 计划太满 | 哪几天缺练、一次能完成多少动作 |
| 动力 | 更短、更固定时间，还是重新开始 |

疼痛问题会明确安全边界：出现刺痛、麻木或肿胀时停止相关动作并做专业评估。

### 03 确认方案

方案卡包含：

- AI 对用户诉求的复述和分析。
- 最近 30 天训练证据（次数、本周完成、平均时长）。
- 具体调整项。
- 「应用调整」「再改一点」。
- 继续输入会作为补充反馈重新生成方案。

## 可执行的调整类型

- **时间**：减少每个训练日的动作数；如果用户说「每周最多 2 天」，同步减少每周训练日，并把个人周目标改为 2。
- **恢复**：每个动作 -1 组，负重 -5%，组间休息 +30 秒。
- **疼痛**：相关肌群动作降到 2 组、负重 -10%；用户点名的动作（如深蹲、箭步蹲）移出计划；提高休息，附安全提示。
- **平台**：主项负重 +2.5%，减少训练日动作数，保留 1–2 次余力。
- **计划太满**：最多 4 个动作、每个动作 -1 组、负重 -5%。
- **动力不足**：最多 3 个动作，先降低启动难度。
- **信息不足**：保守减量，不激进改计划。

应用后会更新：

- `plan.version`
- `plan.updatedAt`
- 每日动作 / 组数 / 负重 / 休息
- 每周训练日（如果用户明确要求）
- `profile.weeklyDays`（如果减少训练日）
- 训练数据、日历计划点、首页周目标
- 对话中的完成卡片

## Web 实现

- `js/coach-adjustment.js`
  - 问题分类、细节追问、方案生成、应用变更
- `js/coach.js`
  - 高端教练聊天 UI
  - 调整阶段横幅、方案卡、完成卡、快捷回复
- `js/actions/plan-adjustment.js`
  - 开始 / 回复 / 应用 / 再改 / 取消 / 查看计划
- `js/actions/coach-paywall.js`
  - 调整模式下 `sendChat` 先进入教练调整流程，不走普通问答
- 入口：
  - 首页 AI 教练卡
  - 计划页当前计划卡
  - 教练页当前计划上下文

## iOS 实现

- `AppStore.requestPlanAdjustment()`：
  - 切换到教练 Tab。
  - 设置 `planAdjustmentRequested`。
- `MainTabView` 使用 `TabView(selection:)` 绑定 `store.selectedTab`。
- `CoachChatView`：
  - 监听 `planAdjustmentRequested` 启动调整。
  - 顶部显示三阶段横幅。
  - 阶段 1 / 2 显示快捷选项。
  - 阶段 3 在输入框上方显示可执行的调整方案卡。
  - `send` 在调整模式下走 `sendPlanAdjustmentMessage`，不走普通远程问答。
- `Core/Services/PlanAdjustmentCoach.swift`：
  - 分类、追问、方案生成、应用变更。
  - 支持减少训练日、移除用户点名的疼痛动作、调整组数 / 负重 / 休息。
  - 应用后更新计划版本、周目标和计划标题。
- 首页 / 计划页的调整按钮只调用 `requestPlanAdjustment()`，不再直接 `adjustPlan()`。

## 验收

- 点「调整计划」进入教练，不再直接修改计划。
- AI 先问问题，至少完成一次细节追问后才给方案。
- 不同问题类型生成不同调整项。
- 用户说「每周最多 2 天」时，计划改为每周 2 天，个人周目标同步。
- 用户点名疼痛动作时，相关动作被移出计划。
- 方案未确认前计划版本不变。
- 用户取消后计划不变。
- 点击应用后计划和首页目标同步更新。
- 教练聊天在 280 / 320 / 390 / 430 和横屏下不横向溢出。
